## Functions in JavaScript

_Function is a block of Reusable codes used to perform some specific tasks. Once it is declared we can use it for n number of times._

_In JavaScript we ccan create a function using function keyword followed by function name followed by parameter block followed by block of reusable code or instructions._

## Parameter & Arguments

_Parameters in functions are variables used to store the passed argument values or functions to the functions. It is declared while decalring the function only after function name._

_Arguments are the data or values which will be passed while calling the function inside parentheses._

## Several Functions are there

1. **Named function:** Named Function in JavaScript refers to a function whihch is having name. It is also known as function declaration or function definition.
2. **Anonymous Function:** Any function created without any name known as anonymous function. Generally this function is used to pass as an argument.
3. **Function Expression:** Any function which is stored inside a variable known as Function expression.
4. **IIFE:** IIFE stands for Immediately Invoked Function expression. This function is called as soon as it has been declared. It will get executed only once in the entire lifecycle.
5. **Arrow Function:** It is a shorthand function introduced in ES6 feature and used to create a function without using any function keyword.
6. **Higher Order Function:** A function which accepts another function as an argument known as Higher Order Function. It can return one new function.
7. **Callback Function:** A function which is passed as an argument to another function known as Callback Function.
8. **Nested Function:** A function created inside another function is known as nested function.
9. **Function Currying:** A function currying is a technique by which we can call a returned function from a function by just adding one extra parentheses.
10. **Generator Function:** A generator function in JavaScript is a special type of function that can pause its execution and resume later, allowing it to produce multiple values over time on demand.

## Closures

_In JavaScript Closures is a function or a mechanism which allows us to access the Parent function variable inside Child function even after execution of parent function._
