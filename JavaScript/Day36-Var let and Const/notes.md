## var, let and const

_All of these three are keywords in JavaScript used to declare variables._

_Variables created using `var` keyword will have global scope whereas `let` and `const` will have block scope and all of these three will follow function or local scope._

## Difference between `var` `let` and `const`

| Keywords | Declaration | Initialization | D & I | Re-Declaration | Re-Initialization | RD & RI |
| -------- | ----------- | -------------- | ----- | -------------- | ----------------- | ------- |
| var      | ✅          | ✅             | ✅    | ✅             | ✅                | ✅      |
| let      | ✅          | ✅             | ✅    | ❌             | ✅                | ❌      |
| const    | ❌          | ❌             | ✅    | ❌             | ❌                | ❌      |
